## 🇺🇿 Oʻzbekcha

HTML, CSS va JavaScript yordamida yaratilgan, foydalanuvchiga daromadlar va xarajatlarni kuzatib borish, shuningdek, jamgʻarmalarni avtomatlashtirishga yordam beradigan oddiy va qulay shaxsiy moliya kalkulyatori.

### ✨ Xususiyatlari
* **Avtomatik taqsimlash:** Har bir kiritilgan daromadning % qismi avtomatik ravishda "Qora kun uchun" fondiga va % qismi "Investitsiyalar" uchun ajratiladi.
* **Tayyor toifalar (Options):** Daromad va xarajatlar uchun tayyor toifalar roʻyxatidan tanlash imkoniyati mavjud.
* **Mahalliy saqlash (LocalStorage):** Maʼlumotlaringiz xavfsiz va maxfiy tarzda faqat brauzeringizda saqlanadi, internetga yuborilmaydi.
* **Moslashuvchan dizayn:** Kompyuter va mobil qurilmalarda birdek qulay ishlaydi.

### 🚀 Qanday ishga tushirish kerak?
1. Kodni yuklab oling yoki nusxalang.
2. `index.html` faylini istalgan brauzerda oching.
3. Moliyangizni nazorat qilishni boshlang!

## 🇷🇺 Русский

Простой и эффективный калькулятор личных финансов, написанный на HTML, CSS и JavaScript. Он помогает пользователям отслеживать доходы и расходы, а также системно формировать накопления.

### ✨ Функции и возможности
* **Автоматическое распределение:** При вводе дохода программа автоматически отправляет % в фонд «На чёрный день» и % на «Инвестиции».
* **Удобный выбор категорий (Options):** Категории расходов и доходов выбираются из готового списка.
* **Полная конфиденциальность (LocalStorage):** Все транзакции сохраняются исключительно в памяти вашего браузера. Данные не передаются в сеть.
* **Адаптивный интерфейс:** Удобно пользоваться как на ПК, так и со смартфона.

### 🚀 Как запустить?
1. Скачайте или скопируйте код проекта.
2. Откройте файл `index.html` в любом удобном браузере.
3. Начните сохранять и приумножать свой бюджет!

## 🇺🇸 English

A simple and lightweight personal finance tracker built with HTML, CSS, and JavaScript. It helps users manage their budget, monitor expenses, and automatically build savings.

### ✨ Features
* **Smart Distribution:** When you log an income, % is automatically allocated to the "Emergency Fund" (Black Day) and % to "Investments".
* **Category Dropdown (Options):** Easily select predefined categories for both income and expenses.
* **Privacy First (LocalStorage):** All data is saved directly in your browser's local storage. Your financial data never leaves your device.
* **Responsive Web Design:** Fully optimized for both desktop and mobile viewports.

### 🚀 How to Run?
1. Download or clone this repository.
2. Open the `index.html` file in any web browser.
3. Take full control of your money!
